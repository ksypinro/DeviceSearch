# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming, whatever someone's background or experience.
- Give and accept constructive feedback gracefully. Focus on what's best for the project and its users.
- No harassment, insults, personal or political attacks, sexualized language, or publishing others' private information.

## Enforcement

Report unacceptable behavior privately to the maintainers through GitHub's "Report content" feature or the contact address on the maintainer's GitHub profile. All reports are reviewed promptly and kept confidential. Maintainers may remove comments, commits and other contributions that break this code, and may ban contributors who repeatedly or seriously do so, following the Contributor Covenant's enforcement guidelines.
